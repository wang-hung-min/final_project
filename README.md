# 🎮 Battle City Game

## 🌟 Project Overview

Battle City is a classic arcade-style tank battle game implemented using the Qt framework. The game allows players to control tanks, navigate through a destructible environment, and engage in combat against various enemy types. This project aims to provide a fun and nostalgic gaming experience while showcasing the capabilities of Qt for game development.

## ✨ Features

### 🕹️ Basic Gameplay Mechanics 
* 🎮 **Game Controls**: Navigate the map, move tanks, and shoot bullets.
* 🗺️ **Map Generation**: Dynamic map generation with destructible elements.
* 💥 **Enemy Interaction**: Destroy enemies, break blocks, pause the game, and play in two-player mode.
* 🏁 **Game Over Logic**: Proper handling of game completion and scoring.

### 🤖 Advanced Enemies 
Different enemy tank types with unique behaviors:
* 🚀 **Fast Tank**: Moves quickly across the map.
* 💪 **Power Tank**: Stronger and more resilient.
* 🛡️ **Armor Tank**: Features enhanced defense capabilities.

### 🎁 Power-ups 
Collectible items to enhance gameplay:
* 💣 **Grenade**: Deals area damage to enemies.
* ⛑️ **Helmet**: Increases player tank defense.
* 🚧 **Shovel**: Allows players to create barriers.
* ⭐ **Star**: Grants temporary invincibility.
* 🚙 **Tank**: Increases player firepower.
* ⏱️ **Timer**: Temporarily slows down enemies.

### 🧱 Advanced Blocks 
Different types of blocks that affect gameplay:
* 🔩 **Steel Wall**: Cannot be destroyed.
* 🌳 **Trees**: Provides cover.
* 💧 **Water**: Slows down tank movement.
* 🧊 **Ice**: Increases tank speed.

### 💾 Game Progress Management 
* Functionality to save and load game progress.

### 📜 History Records 
* View historical records of past games and scores.

## 🛠️ Technologies Used

* 🖼️ **Qt Framework**: For building the graphical user interface and handling game logic.
* 🖥️ **C++**: The primary programming language used for game development.
* 🎨 **Graphics and Sound Libraries**: Leveraging Qt's capabilities to enhance the gaming experience.
